# 遥控菜单与电压实现状态

具体屏幕为SparkFun LCD-23453、SSD1306、1.3英寸128×64、I²C默认7位0x3D，模块3.0–3.3V。PB8/SCL pin32、PB9/SDA pin1；模块有2.2kΩ上拉且没有稳压，不能直接接5V。出处：[官方硬件指南](https://docs.sparkfun.com/SparkFun_Qwiic_OLED_1.3in/hardware_overview/)。仍需板级供电/复位/I²C验收；不混用SH1106/SH1107。

已实现`st_ui`文字模型、原始5×7 ASCII字体与1024B SSD1306页缓存、异步初始化/整帧16数据字节分片。HAL适配中断发送，每次启动即返回，完成/错误通过回调，传输超时锁定故障；清屏发送完后才显示开启。驱动持有一份帧，传输期间拒绝新present，禁止覆盖在用buffer。

主页→采集/状态/设置；旋转换项，按压选择，返回事件回父页并恢复主页选项。开始必须进入确认页，默认选择BACK；STOP只生成采集停止事务。设置里的校准/速率项显示N/A或LOCKED，按压不会发命令。参考了arm_6_axes_0的UiModel/输入/显示分层和返回结构，未接其动作代码。

链路和SELF电压持续显示。状态页有ACQ电压、实际采集状态、TF打开/关闭/故障、同步序号、ADC无数据/过期/错误。ACK只改变事务提示，只有更新序列的实际STATUS确认REC或IDLE。接收时间加发送端测量年龄判断电压，重复/旧STATUS不刷新年龄；停止操作不清零任何测量。未知显示--，有效零电压保留为0.00V。电压档位不表示精确SOC。

ADC12位码→mV函数要求显式参考电压、分压比和已验证标志；未绑定分压不能产生有效电压。四LED仅用于采集端电压档位，阈值严格递增、滞回可配；无效/过期mask=0，不默认满格。物理极性和阈值仍未知，候选PB6–PB9保持GPIO_Input。HAL GPIO适配须verified才会写引脚。

编码器支持16位计数回绕和可配置每档边沿数；按键去抖接受逻辑pressed事件，启动时已按住不会产生事件。实体极性/每档脉冲/去抖值仍由板级决定。PA3的软件语义选为BACK，实物接线未确认。

Host视图为英文ASCII，尚未做中文字体/本地化、实屏刷新率或耗电验收。[预览](ui_host_preview.png)为四页实际C渲染结果，数据是合成值。
