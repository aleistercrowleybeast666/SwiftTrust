# 可更换桥式传感器档案与校准向导需求

仅需求，本轮未实现。普通四/六线传感器通常没有统一数字识别接口；六线SENSE±是激励电压反馈，不保存量程或mV/V。未知传感器应显示“未知/未标定”和原始码，不猜灵敏度，不生成看似可信的N值。未来若采用有独立身份协议的传感器，必须单独验证协议，不能从模拟桥输出自动推断。

## 档案

保存唯一profile_id和版本、型号/序列号（未知则空）、四/六线接法、额定力和明确单位、额定mV/V、允许激励范围、实际激励值/有效性/测量年龄、PGA、ADC参考/时钟/OSR及滤波、零点原始码、系数与拟合方式、参考载荷及其来源/不确定度、标定时间/时间来源/有效性、操作者可选备注、标定有效状态及失效原因。

“额定灵敏度”“实测激励”“整机标定系数”必须是不同字段。质量kg不能直接当作力N；若以已知砝码质量换算力，需明确使用的重力加速度和单位。时间未知时保留空值与来源未知，不编造UTC时间。

## 向导

1. 手动选择/新建档案，核对量程、单位、mV/V及允许激励。无铭牌不自动补值。
2. 确认安装、接线和零载状态，等待信号稳定，采集带统计量的零点；不得在已有载荷时自动归零。
3. 施加已知参考载荷，记录原始码、实际激励及稳定区间，计算零点与斜率。标明是名义mV/V换算还是整机载荷标定。
4. 可选多点加载及卸载，报告残差、重复性、回差；超范围/饱和/CRC状态异常/激励无效不得用作有效标定点。
5. 展示单位、系数、参考点和误差后由用户接受，保存新版本，不悄悄覆盖原档案。日志绑定profile_id和版本。

换传感器、接线、激励/PGA/滤波或机械安装后应提示复核和必要的重新标定。选择旧档案不代表当前传感器已被识别；必须由用户确认匹配。采集中途切换应开新日志段/会话或明确记录版本边界，不能一个文件内静默混用系数。

没有可靠激励监测时，不声称实现激励波动补偿。六线远端激励只有在真实sense电路有效时才可用于比值修正；过期/掉线/未知状态必须保留，不能以接收到新无线包代替激励采样新鲜度。

静态零点与已知载荷标定不证明动态带宽、机械共振、滤波延迟或快速推力测量准确度。这些需后续独立动态验证。向导与档案只服务非点火采集，不提供执行/发射命令。
